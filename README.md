# پامپ‌یاب حرفه‌ای

سروری که ۲۴ ساعته بازار رمزارز رو (از CoinGecko) رصد می‌کنه، رشد یا افت شدید قیمت رو توی چند بازه‌ی زمانی هم‌زمان می‌سنجه، فقط کوین‌های با نقدینگی واقعی رو در نظر می‌گیره، و از طریق یه ربات تلگرام بهت خبر می‌ده — با قابلیت کنترل زنده از همون تلگرام.

## چی جدید اضافه شده نسبت به نسخه‌ی ساده

- **فیلتر نقدینگی:** کوین‌هایی که حجم معاملات ۲۴ساعته‌شون از یه حد مشخص کمتره، نادیده گرفته می‌شن (پامپ‌های کاذب و کم‌عمق حذف می‌شن)
- **چند بازه‌ی زمانی هم‌زمان:** پیش‌فرض ۱، ۵ و ۱۵ دقیقه با هم چک می‌شن؛ توی پیام می‌بینی کدوم بازه(ها) رد شده
- **اطلاعات کامل‌تر در پیام:** قیمت، حجم ۲۴ ساعته، و رتبه‌ی بازار کوین
- **تشخیص افت شدید (دامپ):** همون منطق برعکس، برای سقوط‌های ناگهانی
- **کنترل زنده از تلگرام:** بدون نیاز به تغییر تنظیمات و ری‌دیپلوی

## دستورات تلگرام

بعد از فعال‌شدن ربات، هر کدوم از این‌ها رو توی همون چت بفرست:

- `/status` — وضعیت فعلی (آستانه‌ها، تعداد کوین‌های رصدشده، آخرین بروزرسانی)
- `/threshold 7` — آستانه‌ی پامپ رو روی ۷٪ تنظیم می‌کنه
- `/dumpthreshold 6` — آستانه‌ی افت رو روی ۶٪ تنظیم می‌کنه
- `/pause` — رصد رو موقتاً متوقف می‌کنه
- `/resume` — دوباره فعالش می‌کنه
- `/help` — لیست دستورات

⚠️ نکته: این تغییرات فقط تا وقتی سرویس روشنه اثر دارن؛ اگه سرویس ری‌استارت بشه (مثلاً بعد از یه دیپلوی جدید)، به مقادیر تنظیم‌شده در Variables برمی‌گرده.

## مرحله ۱: ساخت ربات تلگرام

1. توی تلگرام سرچ کن **@BotFather** و باهاش چت کن
2. بفرست: `/newbot`
3. یه اسم و یه یوزرنیم (باید به `bot` ختم بشه) براش انتخاب کن
4. یه **توکن** بهت می‌ده — نگهش دار

## مرحله ۲: گرفتن Chat ID خودت

1. به رباتت یه پیام بفرست، مثلاً «سلام»
2. توی مرورگر باز کن: `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. دنبال `"chat":{"id":` بگرد؛ عددش Chat ID توئه

## مرحله ۳: کلید رایگان CoinGecko

1. برو به [coingecko.com/en/developers/dashboard](https://www.coingecko.com/en/developers/dashboard) و ثبت‌نام کن
2. **"Create Demo API Key"** رو بزن و کلید (`CG-...`) رو نگه دار

## مرحله ۴: دیپلوی روی Railway

1. فایل‌های این پروژه رو توی یه ریپازیتوری گیت‌هاب بذار
2. توی [railway.app](https://railway.app) پروژه‌ی جدید بساز و همون ریپازیتوری رو وصل کن
3. توی تب **Variables** این‌ها رو تنظیم کن:

| متغیر | مقدار پیشنهادی | توضیح |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | (از BotFather) | اجباری |
| `TELEGRAM_CHAT_ID` | (از مرحله‌ی ۲) | اجباری |
| `COINGECKO_API_KEY` | (از مرحله‌ی ۳) | برای جلوگیری از خطای 429 |
| `THRESHOLD_PERCENT` | `5` | آستانه‌ی پامپ (قابل تغییر زنده با `/threshold`) |
| `DUMP_THRESHOLD_PERCENT` | `5` | آستانه‌ی افت (به‌صورت مثبت وارد کن؛ خودش منفی می‌شه) |
| `WINDOWS_MINUTES` | `1,5,15` | بازه‌های زمانی هم‌زمان، با کاما جدا شده |
| `MIN_VOLUME_USD` | `5000000` | حداقل حجم معاملاتی ۲۴ ساعته برای در نظر گرفتن کوین |
| `POLL_SECONDS` | `40` | فاصله‌ی هر بار چک بازار |
| `PAGES` | `1` | تعداد صفحه‌ی ۲۵۰تایی (۱=۲۵۰ کوین، ۲=۵۰۰ کوین) |

4. بعد از دیپلوی، باید پیام فعال‌سازی رو توی تلگرام ببینی

## مرحله ۵ (پیشنهادی): مانیتورینگ سلامت سرویس از بیرون

اگه خود سرویس یا Railway به‌طور کامل از کار بیفته، کد داخلش دیگه نمی‌تونه بهت خبر بده (چون خودش خاموشه). برای این حالت، یه لایه‌ی مانیتورینگ بیرونی مجانی اضافه کن:

1. برو به [uptimerobot.com](https://uptimerobot.com) و یه اکانت رایگان بساز
2. یه Monitor جدید از نوع **HTTP(s)** بساز و آدرس عمومی سرویس Railway‌ت رو بهش بده (توی تب **Network** پروژه، یه دامنه‌ی عمومی فعال کن اگه هنوز نداری)
3. بازه‌ی چک رو روی ۵ دقیقه بذار
4. توی تنظیمات هشدار، ایمیل یا نوتیفیکیشن موبایل UptimeRobot رو فعال کن

این‌طوری حتی اگه کل سرویس کرش کنه یا Railway قطعش کنه، یه سیستم کاملاً مستقل بهت خبر می‌ده.

## نکات

- کوچیک‌کردن بیش‌ازحد آستانه یا بازه‌های خیلی کوتاه، پیام‌های زیاد و نویزی تولید می‌کنه؛ مقادیر پیش‌فرض نقطه‌ی شروع خوبی هستن.
- اگه بازم `rate_limited_429` دیدی، `POLL_SECONDS` رو بیشتر کن یا مطمئن شو `COINGECKO_API_KEY` درست تنظیم شده.
- برای فعال‌کردن دوباره‌ی تغییرات دستی بعد از هر بار /threshold یا /dumpthreshold، لازم نیست کاری بکنی؛ فقط با ری‌استارت سرویس به مقدار پیش‌فرض Variables برمی‌گرده.
