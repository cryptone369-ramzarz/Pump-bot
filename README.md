# پامپ‌یاب لحظه‌ای

این برنامه یه سرور کوچیکه که ۲۴ ساعته به بایننس وصل می‌مونه، رشد قیمت همه‌ی رمزارزهای USDT رو توی یه بازه‌ی زمانی کوتاه (پیش‌فرض ۵ دقیقه) می‌سنجه، و وقتی از آستانه‌ای که تعیین می‌کنی رد بشن، از طریق یه ربات تلگرام بهت پیام می‌ده.

## مرحله ۱: ساخت ربات تلگرام (۲ دقیقه)

1. توی تلگرام سرچ کن **@BotFather** و باهاش چت کن
2. بفرست: `/newbot`
3. یه اسم و یه یوزرنیم (باید به `bot` ختم بشه) براش انتخاب کن
4. یه **توکن** بهت می‌ده شبیه این: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — نگهش دار

## مرحله ۲: گرفتن Chat ID خودت

1. به رباتی که ساختی (با همون یوزرنیمی که دادی) توی تلگرام یه پیام بفرست، مثلاً «سلام»
2. توی مرورگر این آدرس رو باز کن (به‌جای `<TOKEN>` توکن خودت رو بذار):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. توی جواب JSON دنبال `"chat":{"id":` بگرد؛ عددی که جلوشه Chat ID توئه

## مرحله ۳: دیپلوی روی Railway (رایگان برای شروع)

1. برو به [railway.app](https://railway.app) و با گیت‌هابت وارد شو
2. «New Project» → «Deploy from GitHub repo» — یه ریپازیتوری جدید بساز و همین سه فایل (`index.js`, `package.json`, `README.md`) رو توش آپلود کن، بعد همون رو انتخاب کن
   (یا اگه Railway گزینه‌ی آپلود مستقیم پوشه داشت، از همون استفاده کن)
3. بعد از دیپلوی، برو به تب **Variables** پروژه و این‌ها رو اضافه کن:
   - `TELEGRAM_BOT_TOKEN` = توکنی که از BotFather گرفتی
   - `TELEGRAM_CHAT_ID` = عددی که از مرحله‌ی ۲ گرفتی
   - `THRESHOLD_PERCENT` = `5` (یا هر عددی بین ۵ تا ۱۰ که می‌خوای)
   - `WINDOW_MINUTES` = `5` (بازه‌ی زمانی رشد؛ می‌تونی ۱، ۳، ۵، ۱۵ رو امتحان کنی)
4. سرویس ری‌استارت می‌شه و شروع به رصد می‌کنه. چند لحظه بعد باید یه پیام «✅ پامپ‌یاب فعال شد» توی تلگرامت ببینی

از این به بعد، هر وقت رمزارزی توی بازه‌ی تنظیم‌شده به‌اندازه‌ی کافی رشد کنه، پیام تلگرام می‌گیری — کاملاً مستقل از اینکه گوشیت روشن باشه، اپلیکیشن باز باشه، یا حتی خاموش باشی (چون تلگرام خودش پیام رو نگه می‌داره تا آنلاین بشی).

## نکات

- **آستانه‌ی خیلی پایین** (مثلاً زیر ۳٪ با بازه‌ی ۱ دقیقه) باعث پیام‌های زیاد و نویز می‌شه؛ ۵٪ در ۵ دقیقه نقطه‌ی شروع خوبیه.
- برای جلوگیری از هرزنامه، هر نماد فقط یه‌بار در هر «دوره‌ی پامپ» اطلاع می‌ده؛ اگه رشدش زیر آستانه بیاد و دوباره بره بالا، دوباره پیام می‌گیری.
- اگه Railway رایگانش بعد از حجم مصرف قطع شد، همین کد رو می‌تونی بدون تغییر روی Render.com یا یه VPS ساده (مثل یه سرور ۵ دلاری) هم اجرا کنی؛ فقط دستور `npm install && npm start` رو بزن و همون متغیرهای محیطی رو ست کن.
