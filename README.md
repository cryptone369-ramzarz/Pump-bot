# پامپ‌یاب حرفه‌ای — نسخه‌ی کامل

سروری که ۲۴ ساعته بازار رمزارز رو (از CoinGecko) رصد می‌کنه، رشد یا افت شدید قیمت رو توی چند بازه‌ی زمانی هم‌زمان می‌سنجه، فقط کوین‌های با نقدینگی واقعی رو در نظر می‌گیره، به هر هشدار یه امتیاز اطمینان می‌ده، و از طریق یه ربات تلگرام بهت خبر می‌ده — با کنترل کامل و زنده از همون تلگرام.

## قابلیت‌ها

- **فیلتر نقدینگی:** کوین‌های کم‌حجم نادیده گرفته می‌شن
- **چند بازه‌ی زمانی هم‌زمان:** پیش‌فرض ۱، ۵، ۱۵ دقیقه
- **امتیاز اطمینان:** هر هشدار بر اساس حجم، رتبه‌ی بازار، و نسبت حجم‌به‌مارکت‌کپ یه عدد ۰ تا ۱۰۰ می‌گیره (قوی 🟢 / متوسط 🟡 / ضعیف 🔴) — این یه معیار تقریبیه، نه تضمین قطعی که پامپ واقعیه یا نه
- **تشخیص دامپ (افت شدید):** هشدار جدا برای سقوط‌های ناگهانی
- **لیست سیاه/واچ‌لیست:** استیبل‌کوین‌های رایج به‌صورت پیش‌فرض نادیده گرفته می‌شن؛ می‌تونی هر کوینی رو دستی مسدود یا برعکس همیشه رصد کنی (حتی اگه حجمش کمه)
- **تاریخچه‌ی هشدارها:** با `/history` آخرین موارد رو می‌بینی
- **ذخیره‌ی تنظیمات:** تغییراتی که با دستورات تلگرام می‌دی، توی یه فایل ذخیره می‌شن (محدودیتش پایین توضیح داده شده)
- **لینک نمودار:** هر پیام یه لینک مستقیم به صفحه‌ی قیمت همون کوین توی CoinGecko داره
- **تأیید روند ۴ ساعته:** قبل از فرستادن هر هشدار، دو کندل ۴ساعته‌ی اخیر رو چک می‌کنه؛ اگه هم‌جهت با پامپ/دامپ باشن، امتیاز اطمینان بالاتر می‌ره (این دقیقاً همون ایده‌ی «تأیید چند‌تایم‌فریمی»‌ست که ابزارهای تحلیل تکنیکال واقعی هم استفاده می‌کنن)
- **بک‌تست ساده:** با `/backtest 7` می‌بینی از هشدارهایی که واقعاً گرفتی، چند درصدشون تا الان هم‌جهت موندن (این شبیه‌سازی کامل بازار نیست، فقط عملکرد واقعی هشدارهای خودت رو می‌سنجه)
- **دکمه‌های شیشه‌ای تلگرام:** زیر هر پیام پامپ/دامپ، دو دکمه می‌بینی: «📈 نمودار» (باز کردن مستقیم چارت) و «🚫 مسدود کن» (بدون تایپ‌کردن، همون‌جا کوین رو به لیست سیاه اضافه می‌کنه)
- **آلارم قیمت چندگانه:** برای هر کوین هرچندتا قیمت هدف بذار (مثلاً BTC روی ۶۰۰۰۰ و ۷۰۰۰۰ و ۷۵۰۰۰)؛ بالاتر یا پایین‌تر بودن هر کدوم خودکار نسبت به قیمت فعلی تشخیص داده می‌شه. هر آلارم یک‌بار مصرفه و بعد از فعال‌شدن پاک می‌شه
- **گزارش هر کوین:** با `/report BTC` همه‌ی هشدارهای پامپ، دامپ و آلارم‌های قیمت یه کوین رو با قیمت زمان هشدار و وضعیت الانش می‌بینی
- **کنترل کامل از تلگرام:** بدون نیاز به تغییر تنظیمات روی Railway

## دستورات تلگرام

- `/status` — وضعیت فعلی
- `/threshold 7` — آستانه‌ی پامپ رو ۷٪ می‌کنه
- `/dumpthreshold 6` — آستانه‌ی افت رو ۶٪ می‌کنه
- `/pause` / `/resume` — توقف و از سرگیری رصد پامپ/دامپ (آلارم‌های قیمت در حالت توقف هم فعال می‌مونن)
- `/watch BTC` — این کوین همیشه رصد بشه، حتی اگه حجمش زیر حد تعیین‌شده باشه
- `/unwatch BTC` — حذف از واچ‌لیست
- `/watchlist` — نمایش واچ‌لیست
- `/blacklist DOGE` — این کوین رو کاملاً نادیده بگیر
- `/unblacklist DOGE` — حذف از لیست سیاه
- `/blacklistshow` — نمایش لیست سیاه
- `/history` — آخرین ۱۰ هشدار ثبت‌شده
- `/backtest 7` — عملکرد واقعی هشدارهای ۷ روز اخیر (عدد رو می‌تونی عوض کنی)
- `/alert BTC 70000 75000 60000` — ثبت چندتا آلارم قیمت برای یه کوین (قیمت‌ها با فاصله؛ ارقام فارسی هم قبوله)
- `/alerts` یا `/alerts BTC` — لیست آلارم‌های قیمت، با دکمه‌ی حذف زیر هر کدوم
- `/delalert BTC 70000` — حذف یه آلارم؛ `/delalert BTC` همه‌ی آلارم‌های اون کوین رو پاک می‌کنه
- `/report BTC` یا `/report BTC 7` — گزارش هشدارهای یه کوین (پیش‌فرض ۳۰ روز اخیر)
- `/dynamic on` یا `/dynamic off` — روشن/خاموش‌کردن آستانه‌ی پویا
- `/dynamicfactor 0.5` — تنظیم ضریب آستانه‌ی پویا (هرچی بیشتر، برای کوین‌های پرنوسان سخت‌گیرتر می‌شه)
- `/volumealert on` یا `/volumealert off` — روشن/خاموش‌کردن هشدار جهش حجم
- `/volumefactor 3` — چند برابر حجم معمول، به‌عنوان جهش حساب بشه
- `/mute DOGE 6h` — سکوت موقت (واحدها: m برای دقیقه، h برای ساعت، d برای روز)
- `/unmute DOGE` — لغو سکوت زودتر از موعد
- `/mutes` — نمایش کوین‌های ساکت‌شده و زمان پایانشون
- `/export 30` — خروجی CSV از تاریخچه‌ی ۳۰ روز اخیر
- `/dailysummary on` یا `/dailysummary off` — روشن/خاموش‌کردن خلاصه‌ی روزانه
- `/summaryhour 9` — تغییر ساعت ارسال خلاصه‌ی روزانه (وقت ایران)
- `/summarynow` — ارسال فوری خلاصه (برای تست، بدون نیاز به صبر تا فردا)
- `/menu` — منوی دکمه‌ای
- `/help` — راهنما

## درباره‌ی امتیاز اطمینان

این عدد **جایگزین تحلیل واقعی نیست** — ترکیبی از چند سیگنال (حجم معاملات، رتبه‌ی بازار، نسبت حجم به ارزش‌بازار، و هم‌جهت‌بودن با روند ۴ ساعته) هست که کمک می‌کنه سریع تشخیص بدی کدوم هشدارها بیشتر ارزش بررسی دارن. عدد بالا لزوماً به‌معنی «حتماً بخر» نیست، و عدد پایین لزوماً به‌معنی «کاذبه» نیست — فقط یه فیلتر اولیه‌ست.

## درباره‌ی بک‌تست

`/backtest` یه شبیه‌سازی کامل تاریخی روی کل بازار نیست (این کار با API رایگان برای صدها کوین عملاً ممکن نیست). به‌جاش، عملکرد واقعیِ همون هشدارهایی که ربات برات فرستاده رو می‌سنجه: از هر هشدار پامپ/دامپ که ثبت شده، چک می‌کنه قیمت الان نسبت به لحظه‌ی هشدار هنوز هم‌جهت مونده یا برگشته. این یه معیار عملی و صادقانه‌ست برای اینکه ببینی آستانه‌هات چقدر خوب عمل می‌کنن — نه یه پیش‌بینی از آینده.

## دائمی‌کردن ذخیره‌ی تنظیمات و آلارم‌ها (Volume)

تنظیمات، واچ‌لیست، لیست سیاه، و همه‌ی آلارم‌های قیمتی توی یه فایل کنار کد ذخیره می‌شن. مشکل: روی Railway، هر بار که کد رو آپدیت و Commit می‌کنی، یه کانتینر کاملاً تازه ساخته می‌شه و این فایل از بین می‌ره — یعنی همه‌ی آلارم‌هایی که گذاشته بودی پاک می‌شن.

راه‌حل دائمی: یه **Volume** (فضای ذخیره‌ی مستقل از کد) به سرویس وصل کن که مستقل از دیپلوی‌ها باقی می‌مونه:

1. توی پروژه‌ی Railway، وارد سرویس Pump-bot شو
2. دنبال تب یا دکمه‌ی **Volumes** بگرد (معمولاً کنار Variables/Settings) و **New Volume** رو بزن
3. یه مسیر برای Mount انتخاب کن، مثلاً `/data`
4. توی تب **Variables**، یه متغیر جدید اضافه کن:
   - `STATE_DIR` = `/data`
5. سرویس ری‌استارت می‌شه؛ از این به بعد فایل تنظیمات توی `/data/state.json` ذخیره می‌شه، روی همون Volume — که با آپدیت کد و Commit جدید، دیگه پاک نمی‌شه.

اگه `STATE_DIR` رو تنظیم نکنی، فایل مثل قبل کنار کد ذخیره می‌شه و با هر دیپلوی جدید از بین می‌ره.

## دکمه‌ی منوی تلگرام

با شروع سرویس، ربات خودکار لیست دستورات رو توی تلگرام ثبت می‌کنه (`setMyCommands`) و دکمه‌ی منو (آیکون کنار جعبه‌ی تایپ، پایین‌سمت‌چپ صفحه‌ی چت) رو فعال می‌کنه. با زدنش، لیست کامل دستورات با توضیح کوتاه هرکدوم باز می‌شه — می‌تونی از همون‌جا هرکدوم رو انتخاب کنی، یا همچنان از `/menu` برای منوی دکمه‌ای دسته‌بندی‌شده استفاده کنی. این دو مکمل همدیگه‌ن: دکمه‌ی منوی تلگرام برای دسترسی سریع به اسم دستورات، `/menu` برای انجام کارها با لمس بدون تایپ.

## منوی دکمه‌ای

با `/menu` یه منوی دکمه‌ای باز می‌شه که همه‌ی بخش‌ها رو دسته‌بندی‌شده نشون می‌ده: وضعیت و کنترل، آستانه‌ها، واچ‌لیست/لیست سیاه، آلارم قیمت، سکوت موقت، گزارش‌ها، و تنظیمات پیشرفته. کارهایی مثل روشن/خاموش‌کردن یه تنظیم، دیدن لیست‌ها، یا گرفتن گزارش، مستقیم با لمس دکمه انجام می‌شن. برای کارهایی که به یه عدد یا اسم کوین نیاز دارن (مثل تنظیم آستانه یا افزودن آلارم قیمت)، چون تلگرام فرم واقعی نداره، دکمه دستور دقیق رو نشونت می‌ده که فقط کپی/تایپ کنی.

## قابلیت‌های جدید

- **آستانه‌ی پویا:** به‌جای یه آستانه‌ی ثابت برای همه‌ی کوین‌ها، ربات نوسان معمول ۲۴ساعته‌ی هر کوین رو یاد می‌گیره. کوین‌های ذاتاً پرنوسان (مثل میم‌کوین‌ها) نیاز به حرکت بزرگ‌تری دارن تا هشدار بدن؛ کوین‌های آروم (مثل بیت‌کوین) با همون آستانه‌ی پایه هشدار می‌دن. آستانه‌ی خودت (`/threshold`) همیشه به‌عنوان کف در نظر گرفته می‌شه، هیچ‌وقت پایین‌تر از اون نمی‌ره.
- **هشدار جهش حجم معاملات:** مستقل از حرکت قیمت، اگه حجم معاملات یه کوین ناگهان چند برابر میانگین معمولش بشه، جدا خبر می‌ده — این می‌تونه قبل از خود پامپ اتفاق بیفته.
- **سکوت موقت یه کوین:** `/mute DOGE 6h` این کوین رو برای ۶ ساعت از هشدارهای پامپ/دامپ/حجم خارج می‌کنه (آلارم‌های قیمتی دستی که خودت گذاشتی همچنان فعال می‌مونن).
- **خروجی CSV:** با `/export 30` کل تاریخچه‌ی ۳۰ روز اخیر رو به‌صورت یه فایل CSV می‌گیری، برای تحلیل توی اکسل یا گوگل شیت.
- **خلاصه‌ی روزانه:** هر روز ساعت مشخصی (پیش‌فرض ۹ صبح به وقت ایران) یه پیام خلاصه از عملکرد ۲۴ ساعت اخیر می‌گیری: تعداد پامپ/دامپ/جهش حجم، و بهترین/بدترین حرکت روز.

## نشونه‌های رنگی

تلگرام اجازه‌ی متن یا باکس رنگی نمی‌ده. برای پامپ و افت از این نشونه‌ها استفاده می‌شه:
- **پامپ:** 🌲🌲🌲 توی پیام اصلی هشدار (سبز و به‌وضوح قابل تشخیص)، و 🌲 تک‌تایی توی جاهای فشرده‌تر مثل لیست آلارم‌ها، دکمه‌ها و تاریخچه
- **افت:** 🔻🔻🔻 توی پیام اصلی هشدار، و 🔻 تک‌تایی توی جاهای فشرده

(نکته‌ی فنی: مثلث سبز به‌صورت رسمی توی استاندارد ایموجی تعریف نشده و هیچ پلتفرمی نمی‌تونه واقعاً رنگش کنه، برای همین به‌جاش از درخت 🌲 استفاده شده که هم شکلش مثلثیه هم رنگش تضمینی سبزه.)

## درباره‌ی آلارم قیمت

- هر آلارم **یک‌بار مصرفه**: وقتی قیمت به هدف رسید (یا ازش رد شد)، پیام می‌گیری و آلارم پاک می‌شه.
- اگه قیمتی رو وارد کنی که همین الان هم برقراره (مثلاً قیمت هدف پایین‌تر از قیمت فعلیه ولی به‌صورت `above` خواسته باشی)، ثبت نمی‌شه و دلیلش بهت گفته می‌شه.
- قیمت‌های اعشاری رو با نقطه بنویس (`0.0125`) و چندتا قیمت رو با فاصله از هم جدا کن. ورودی مبهم مثل `0,5` عمداً رد می‌شه تا اشتباه ثبت نشه.
- آلارم‌ها برای هر کوینی کار می‌کنن، حتی کوین‌های کوچیکی که توی ۲۵۰ کوین برتر نیستن.
- برای یه کوین می‌تونی هرچندتا آلارم بخوای داشته باشی — هم توی یه دستور (`/alert BTC 70000 75000 60000`)، هم با چندبار فرستادن `/alert` در زمان‌های مختلف؛ همه با هم جمع می‌شن.
- برای اجباری‌کردن جهت یه قیمت خاص، کلمه‌ی `above` یا `below` رو درست قبلش بذار: `/alert BTC above 70000 below 60000`. بدون این کلمه‌ها، جهت هر قیمت خودکار (نسبت به قیمت فعلی لحظه‌ی ثبت) تشخیص داده می‌شه.

## مرحله ۱: ساخت ربات تلگرام

1. توی تلگرام سرچ کن **@BotFather** و باهاش چت کن
2. بفرست: `/newbot`
3. یه اسم و یوزرنیم (باید به `bot` ختم بشه) انتخاب کن
4. توکن رو نگه دار

## مرحله ۲: گرفتن Chat ID

1. به ربات پیام بده، مثلاً «سلام»
2. باز کن: `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. عدد جلوی `"chat":{"id":` رو بردار

## مرحله ۳: کلید رایگان CoinGecko

1. [coingecko.com/en/developers/dashboard](https://www.coingecko.com/en/developers/dashboard) → ثبت‌نام
2. **Create Demo API Key** → کلید (`CG-...`) رو نگه دار

## مرحله ۴: دیپلوی روی Railway

1. فایل‌ها رو توی یه ریپازیتوری گیت‌هاب بذار
2. توی [railway.app](https://railway.app) پروژه‌ی جدید بساز و همون ریپازیتوری رو وصل کن
3. توی تب **Variables**:

| متغیر | مقدار پیشنهادی | توضیح |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | (از BotFather) | اجباری |
| `TELEGRAM_CHAT_ID` | (از مرحله‌ی ۲) | اجباری |
| `COINGECKO_API_KEY` | (از مرحله‌ی ۳) | برای جلوگیری از خطای 429 |
| `THRESHOLD_PERCENT` | `5` | آستانه‌ی پامپ (قابل تغییر زنده) |
| `DUMP_THRESHOLD_PERCENT` | `5` | آستانه‌ی افت (مثبت وارد کن) |
| `WINDOWS_MINUTES` | `1,5,15` | بازه‌های زمانی، با کاما جدا |
| `MIN_VOLUME_USD` | `5000000` | حداقل حجم معاملاتی ۲۴ ساعته |
| `BLACKLIST_IDS` | (اختیاری) | آی‌دی‌های اضافی CoinGecko برای نادیده‌گرفتن، با کاما جدا |
| `POLL_SECONDS` | `15` | فاصله‌ی هر بار چک بازار — با این مقدار حتماً `COINGECKO_API_KEY` رو هم تنظیم کن، وگرنه سریع به خطای ۴۲۹ می‌خوری |
| `PAGES` | `1` | ۱=۲۵۰ کوین برتر، ۲=۵۰۰ کوین |
| `TIMEZONE` | `Asia/Tehran` | منطقه‌ی زمانی برای نمایش ساعت هشدارها (پیش‌فرض ساعت ایران) |
| `DYNAMIC_THRESHOLD_FACTOR` | `0.4` | ضریب آستانه‌ی پویا (قابل تغییر زنده با `/dynamicfactor`) |
| `VOLUME_SPIKE_MULTIPLIER` | `2.5` | چند برابر حجم معمول، جهش حساب بشه (قابل تغییر زنده با `/volumefactor`) |
| `DAILY_SUMMARY_HOUR` | `9` | ساعت ارسال خلاصه‌ی روزانه، به وقت ایران (قابل تغییر زنده با `/summaryhour`) |
| `STATE_DIR` | (اختیاری) | اگه Volume وصل کردی، مسیر Mount رو اینجا بذار (مثلاً `/data`) تا تنظیمات و آلارم‌ها با هر دیپلوی پاک نشن |

4. بعد از دیپلوی، پیام فعال‌سازی رو توی تلگرام می‌بینی؛ برای شروع بفرست `/help`

## مرحله ۵ (پیشنهادی): مانیتورینگ بیرونی سلامت سرویس

1. [uptimerobot.com](https://uptimerobot.com) → اکانت رایگان
2. Monitor نوع **HTTP(s)** بساز، آدرس عمومی سرویس Railway (از تب Network) رو بده
3. بازه‌ی چک: ۵ دقیقه؛ هشدار ایمیل/موبایل رو فعال کن

این‌طوری حتی اگه کل سرویس از کار بیفته، یه سیستم مستقل بهت خبر می‌ده.

## نکات

- آستانه یا بازه‌ی خیلی کوچیک = پیام زیاد و نویزی.
- خطای `rate_limited_429` بیشتر شد → `POLL_SECONDS` رو زیاد کن یا `COINGECKO_API_KEY` رو چک کن.
- `/watch` برای کوین‌های کوچیک هم کار می‌کنه، حتی اگه توی ۲۵۰/۵۰۰ کوین برتر نباشن — با یه جست‌وجوی جداگانه پیدا و اضافه می‌شن.
